# To-Do List

Лабораторная работа №2 по предмету «Web-программирование»: список задач на чистом JavaScript с DOM API, без фреймворков.

## Возможности

- добавление, удаление и редактирование задач (текст и срок);
- отметка задачи выполненной;
- сортировка по дате (сначала ранние / сначала поздние);
- фильтр по статусу: все, невыполненные, выполненные;
- поиск по названию;
- перетаскивание задач для смены порядка (мышью, пальцем, а также стрелками ↑↓ с клавиатуры);
- сохранение задач и фильтра в localStorage;
- адаптивная вёрстка (flex/grid) для ноутбука, планшета и телефона.

## Как это устроено

- В `index.html` только каркас и подключение `js/script.js`.
- Вся страница строится из JavaScript методами DOM (`createElement`, `append`, `textContent`), без `innerHTML`.
- Стили лежат в `css/style.css` и подключаются из скрипта.

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт доступен на `http://localhost:8000`.
